## 0. 架构总览

```
MCP 客户端 (opencode / Claude Desktop / Cursor ...)
        │  stdio (JSON-RPC)
        ▼
FastMCP 封装层 (server.py, 4 个工具)
        │
        ▼
mem0ai (OSS) 记忆引擎
        ├── 抽取 LLM ──── OpenAI 兼容 API（如 uuapi.io），只走 chat 端点
        ├── 嵌入模型 ──── FastEmbed 本地 ONNX（首次下载权重后完全离线）
        ├── 向量库  ──── Chroma 嵌入式（本地目录持久化）
        └── 历史库  ──── SQLite（本地文件）
```

**产物**：一个 Python 进程 + 一个数据目录。备份 = 复制目录。

**工具面**：`add_memory` / `search_memories` / `list_memories` / `delete_memory`

### ❓ 检查点 Q3：网络与代理

Windows 上 Python **不读注册表系统代理**，直连可能超时。先探测：

```powershell
# 查系统代理设置
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select ProxyEnable, ProxyServer
# 查代理进程监听端口（区分 socks5 / http）
netstat -ano | findstr "<代理端口>"
# 用 curl 验证协议（socks5 示例）
curl.exe -s --connect-timeout 5 --proxy socks5://127.0.0.1:<端口> https://<你的LLM域名>/ -I
```

- 若无需代理（可直连 LLM API）：跳过，后续配置中删掉代理相关行
- 若代理是 socks5：Python 侧需 `httpx[socks]`（提供 socksio）
- 若代理是 http：直接用 `http://127.0.0.1:<端口>`

### ❓ 检查点 Q4：探测结果确认

实战中踩过的坑，逐一对照：
- **502 Bad Gateway** ≠ 模型名错，可能是上游临时挂了；换同组其他模型对照测试

### Step 4：写 MCP 封装 `server.py`

完整可用版本（按需改环境变量默认值）：

```python
"""mem0-local: local memory MCP server."""
import json, os, sys
from pathlib import Path

os.environ.setdefault("MEM0_TELEMETRY", "False")        # mem0 遥测关
os.environ.setdefault("ANONYMIZED_TELEMETRY", "False")  # chroma 遥测关
os.environ.setdefault("HF_HUB_OFFLINE", "1")            # 模型已缓存，跳过 HF 联网检查
os.environ.setdefault("TRANSFORMERS_OFFLINE", "1")
# 代理（无代理环境删除以下三行）
os.environ.setdefault("ALL_PROXY", "socks5://127.0.0.1:10808")
os.environ.setdefault("HTTPS_PROXY", "socks5://127.0.0.1:10808")
os.environ.setdefault("HTTP_PROXY", "socks5://127.0.0.1:10808")

HOME = Path.home()
DATA_DIR = HOME / "mem0-local" / "data"
AUTH_JSON = HOME / ".local" / "share" / "opencode" / "auth.json"  # 按实际 key 存放处改

LLM_MODEL = os.environ.get("MEM0_LLM_MODEL", "gemini-3.7-flash")
LLM_BASE_URL = os.environ.get("MEM0_LLM_BASE_URL", "https://uuapi.io/v1")
EMBED_MODEL = os.environ.get("MEM0_EMBED_MODEL", "jinaai/jina-embeddings-v2-base-zh")
USER_ID = os.environ.get("MEM0_USER_ID", "june")

def resolve_api_key(model: str) -> str:
    key = os.environ.get("MEM0_API_KEY")
    if key:
        return key
    auth = json.loads(AUTH_JSON.read_text(encoding="utf-8"))
    # 按模型前缀选 key 组（按你的中转商实际结构改）
    if model.startswith("gemini"):
        return auth.get("uugemini", {}).get("key") or auth.get("uugpt", {}).get("key")
    return auth.get("uugpt", {}).get("key")

_memory = None

def _pin_fastembed_cache():
    """把嵌入权重固定到稳定目录（Temp 会被清理）。"""
    import fastembed
    target = DATA_DIR / "models"
    target.mkdir(parents=True, exist_ok=True)
    orig = fastembed.TextEmbedding.__init__
    def patched(self, *a, **kw):
        kw.setdefault("cache_dir", str(target))
        orig(self, *a, **kw)
    fastembed.TextEmbedding.__init__ = patched

def get_memory():
    global _memory
    if _memory is None:
        from mem0 import Memory
        _pin_fastembed_cache()
        _memory = Memory.from_config({
            "llm": {"provider": "openai", "config": {
                "model": LLM_MODEL, "api_key": resolve_api_key(LLM_MODEL),
                "openai_base_url": LLM_BASE_URL, "temperature": 0.1}},
            "embedder": {"provider": "fastembed", "config": {"model": EMBED_MODEL}},
            "vector_store": {"provider": "chroma", "config": {
                "path": str(DATA_DIR / "chroma"), "collection_name": "mem0"}},
            "history_db_path": str(DATA_DIR / "history.db"),
        })
    return _memory

from fastmcp import FastMCP
mcp = FastMCP("mem0-local")

@mcp.tool
def add_memory(text: str, tags: list[str] | None = None) -> str:
    """Store a durable fact, decision, or preference. The LLM extracts and
    deduplicates facts automatically."""
    metadata = {"tags": tags} if tags else None
    result = get_memory().add(text, user_id=USER_ID, metadata=metadata, infer=True)
    events = result.get("results", [])
    if not events:
        return "No new memory stored (nothing extractable or duplicate)."
    return "\n".join(f"{e.get('event')}: {e.get('memory')}" for e in events)

@mcp.tool
def search_memories(query: str, limit: int = 5) -> str:
    """Semantic search over stored memories."""
    result = get_memory().search(query, filters={"user_id": USER_ID}, top_k=limit, threshold=0.1)
    items = result.get("results", [])
    if not items:
        return "No matching memories."
    return "\n".join(f"- [{m.get('score', 0):.2f}] {m.get('memory')}" for m in items)

@mcp.tool
def list_memories(limit: int = 50) -> str:
    """List recently stored memories."""
    result = get_memory().get_all(filters={"user_id": USER_ID}, top_k=limit)
    items = result.get("results", [])
    if not items:
        return "Memory store is empty."
    return "\n".join(f"- {m.get('memory')} (id: {m.get('id')})" for m in items)

@mcp.tool
def delete_memory(memory_id: str) -> str:
    """Delete one memory by its id."""
    get_memory().delete(memory_id)
    return f"Deleted {memory_id}."

if __name__ == "__main__":
    import threading
    def _warmup():
        try:
            get_memory()
            print("[mem0-local] warmup complete", file=sys.stderr)
        except Exception as e:
            print(f"[mem0-local] warmup failed: {e}", file=sys.stderr)
    threading.Thread(target=_warmup, daemon=True).start()
    mcp.run()
```

**设计要点**（每条都对应一个真实踩坑）：
1. 遥测全关 + `HF_HUB_OFFLINE=1`：消除首次调用的隐性网络延迟
2. `_pin_fastembed_cache`：权重固定到 `data/models`，防 Temp 清理后重新下载 600MB 导致超时
3. 后台预热线程：服务器启动即加载引擎，工具调用到达时已热
4. 所有日志走 **stderr**：stdio MCP 的 stdout 是协议通道，任何 print 污染都会导致客户端挂死
5. key 从 opencode auth.json 读取：不复制秘密，换 key 自动同步

## 3. 接入 MCP 客户端

### opencode（全局配置 `~/.config/opencode/opencode.jsonc`）

```jsonc
{
  "mcp": {
    "mem0": {
      "type": "local",
      "command": [
        "C:\\<你的路径>\\mem0-local\\.venv\\Scripts\\python.exe",
        "C:\\<你的路径>\\mem0-local\\server.py"
      ],
      "enabled": true
    }
  },
  "experimental": {
    "mcp_timeout": 120000
  }
}
```

- `command` 必须是字符串数组；`type` 必填
- `mcp_timeout` 调到 120s：给冷启动兜底（预热正常后实际调用 <1s）

### 其他客户端（通用 MCP stdio 形态）

```json
{ "mcpServers": { "mem0": { "command": "<python.exe 绝对路径>", "args": ["<server.py 绝对路径>"] } } }
```

## 4. 验证与重启

### ❓ 检查点 Q5：完全重启

**MCP 配置只在客户端进程启动时加载一次。** 新建会话/标签页不会重新挂载；
进程内 MCP 一旦被标记死亡（如超时），后续会话都拿不到工具。

正确操作：**完全退出客户端进程 → 重新启动 → 新会话中调用 `list_memories` 验证**。

## 5. 故障排查手册（实战踩坑全集）

| 症状 | 根因 | 修复 |
|---|---|---|
| MCP 首次调用 `-32001 Request timed out` | 冷启动初始化（mem0 导入+模型加载+HF 联网检查）超过客户端超时 | `HF_HUB_OFFLINE=1` + 后台预热 + `mcp_timeout: 120000` |
| 后续调用 `-32000 Connection closed` | 超时后进程被客户端断开/标记死亡 | 修复根因后**完全重启**客户端进程 |
| LLM 报 502 | 中转商上游抖动，或模型名在该 key 组不可用 | 换同组模型对照探测（见 probe.py） |
| `model_not_found` | 中转商按模型组分 key | 用对应组的 key（如 gemini 组 key 调 gemini） |
| Python 请求挂死但 curl 正常 | Windows 系统代理是注册表级，Python 不读；或代理是 socks5 而按 http 用 | `netstat` 确认端口协议；装 `httpx[socks]`；显式设 `ALL_PROXY` |
| 嵌入模型下载慢/失败 | HF 直连受限 | 走代理下载一次，之后 `HF_HUB_OFFLINE=1` 完全离线 |
| 客户端收到工具响应但乱码 | 终端代码页问题（cp936） | `chcp 65001`；库内是 UTF-8，数据无损 |
| 工具列表为空/未挂载 | 配置未加载（没重启进程）或 server.py 启动即崩 | 先跑 Step 6 原始协议测试定位 |
| agent 绕过工具手搓查询 | 技能文件缺少硬纪律 | 补"禁止直查"规则（见 Step 3 配套引导） |
| PowerShell 传 JSON 给 curl 报错 | PowerShell 引号转义地狱 | 一律改用 Python 脚本发请求 |
